# Interstellar roadmap

## Current desktop release

- WPF glass overlay with normal Windows taskbar and Alt+Tab presence.
- One-shot primary-monitor GDI screenshot on Ctrl+Shift+S.
- Clipboard paste to an external focused control, or attachment to the in-app Assistant composer.
- Streaming AI providers with an optional Fast responses profile.
- Multiple independent WebView2 browser tabs.
- Windows built-in VPN profile picker and connect/disconnect controls.
- DPAPI-protected API keys saved through Settings.

## Possible follow-on work

- User-selected rectangular screen crops while keeping the one-shot capture model.
- Saved browser tab groups and named assistant conversations.
- Better VPN status reporting through the Windows RAS APIs.
- Provider/model presets with explicit latency and cost trade-offs.

No background screen watcher, notification-area resident mode, hidden process, or kernel component is part of the current app.
